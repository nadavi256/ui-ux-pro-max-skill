# מציאה — לוח מודעות יד שנייה

אפליקציית web (mobile-first, RTL מלא) לקנייה ומכירה של פריטי יד שנייה: פרסום מודעות עם
תמונות, חיפוש וסינון, מועדפים, וצ׳אט בין קונה למוכר.

## מה יש בגרסה הזו

| אזור | יכולות |
|---|---|
| **דף הבית** | חיפוש כ-CTA ראשי, קטגוריות, מודעות חדשות, "למסירה בחינם" |
| **חיפוש** `/search` | טקסט חופשי, קטגוריה, עיר, טווח מחיר, מצב, מיון, עימוד — הכל ב-URL (שיתוף + SEO) |
| **מודעה** `/listing/[id]` | גלריה, פרטים, מונה צפיות, הצגת טלפון / וואטסאפ, שליחת הודעה, שמירה, מודעות דומות, JSON-LD |
| **פרסום / עריכה** | עד 6 תמונות (דחיסה ל-WebP בדפדפן), בחירת תמונה ראשית, "למסירה", ולידציה בשרת (Zod) |
| **אזור אישי** `/me` | המודעות שלי + סטטוס (פעילה / נמכר / מוסתרת), צפיות ושמירות, עריכת פרופיל |
| **הודעות** `/messages` | שיחה לכל (מודעה, קונה), סימון נקרא/לא נקרא, התראה בתפריט |
| **מועדפים** `/favorites` | שמירה אופטימית (בלי רענון) |

## סטאק

Next.js 16 (App Router) · Prisma 7 + PostgreSQL · Auth.js v5 (אימייל + סיסמה) · Tailwind CSS v4 · Zod · lucide-react.

תמונות שמועלות נשמרות ב-Postgres ומוגשות מ-`/api/images/[id]` עם cache קבוע — אין צורך בשירות
אחסון נוסף כדי להתחיל. (כשהנפח יגדל כדאי לעבור ל-Vercel Blob / S3; המודל `ListingImage` כבר תומך
גם ב-`url` חיצוני.)

עיצוב: נבנה לפי מערכת העיצוב שהפיק `ui-ux-pro-max` לתבנית "Marketplace / Directory" — סגול
אמון + ירוק לפעולות (פרסום / יצירת קשר), פונט Rubik, יעדי מגע ≥44px, ניגודיות AA, ניווט תחתון במובייל.

## הרצה מקומית

```bash
cd marketplace
npm install
cp .env.example .env        # מלאו DATABASE_URL ו-AUTH_SECRET
npm run db:push             # יצירת הטבלאות
npm run db:seed             # קטגוריות + 18 מודעות דמו + משתמש מנהל
npm run dev
```

משתמשי דמו (אחרי seed): `noa@demo.local` / `yossi@demo.local` / `dana@demo.local`, סיסמה `Demo12345!`.

> הקטגוריות נוצרות אוטומטית גם בלי seed, בפעם הראשונה שהן נטענות — כך שמסד נתונים ריק בפרודקשן עובד מיד.

## פריסה ל-Vercel

1. New Project → בחרו את ה-repo → **Root Directory: `marketplace`**.
2. Storage → Create Database → Postgres (Neon) וחברו לפרויקט (משתני `POSTGRES_*` נקלטים אוטומטית).
3. הוסיפו `AUTH_SECRET` ו-`NEXT_PUBLIC_SITE_URL`.
4. Deploy — `npm run build` מריץ `prisma db push` ויוצר את הטבלאות.

## השלבים הבאים (הצעה)

- התחברות עם Google / אימות SMS לטלפון
- העלאת תמונות ל-Blob storage
- התראות (מייל / push) על הודעה חדשה, וצ׳אט בזמן אמת
- דיווח על מודעה + פאנל ניהול
- "הקפצת" מודעה בתשלום, מודעות מקודמות
- קטגוריות ייעודיות לרכב ונדל״ן עם שדות מותאמים
